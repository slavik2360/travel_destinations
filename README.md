# travel_destinations

Экспертная система подбора направления для путешествия (PyQt5): последовательность вопросов
Да/Нет по бюджету, континенту, типу отдыха, сезону, продолжительности, визовым предпочтениям
и интересам, после чего система предлагает конкретное направление из базы знаний - либо в
режиме классического логического вывода с ослаблением условий, либо в имитационном
«ИИ-режиме» с оценкой уверенности. К результату подтягивается фотография направления
(Wikipedia), а для явно невозможных сочетаний (например, пляжный отдых в Антарктиде) система
честно объясняет, почему так, и предлагает реальную альтернативу.

## Скачать и запустить (без установки Python)

Готовые сборки для Windows и macOS собираются автоматически в
[GitHub Actions](../../actions/workflows/build.yml) при выходе новой версии (тег `vX.Y.Z`) и
прикрепляются к разделу [Releases](../../releases). Скачайте архив под свою систему,
распакуйте и запустите - никаких дополнительных установок не требуется.

Если готовой сборки под свою систему нет - запустите workflow вручную (вкладка **Actions**
→ **Build standalone app** → **Run workflow**) и заберите файлы из артефактов запуска.

## Запуск из исходного кода

```bash
python3 -m venv env
source env/bin/activate   # Windows: env\Scripts\activate
pip install -r requirements.txt
python MyProgram/main.py
```

## Сборка приложения самостоятельно

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name TravelExpert MyProgram/main.py
```

Готовый файл появится в папке `dist/` (`TravelExpert.exe` на Windows, `TravelExpert.app` на
macOS).

## Структура

- `MyProgram/main.py` - всё приложение: база знаний, логика подбора, интерфейс на PyQt5.
- `MyProgram/shema.html` - схема логики мастера вопросов и механизма вывода (открыть в браузере).
- `MyProgram/db-schema.html` - ER-схема базы данных: таблицы, ключи и связи между ними
  (открыть в браузере, диаграмма строится через Mermaid).
