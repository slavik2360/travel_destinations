# travel_destinations

Экспертная система подбора направления для путешествия (PyQt5): последовательность вопросов
Да/Нет по бюджету, континенту, типу отдыха, сезону, продолжительности, визовым предпочтениям
и интересам, после чего система предлагает конкретное направление из базы знаний - либо в
режиме классического логического вывода с ослаблением условий, либо собственным ИИ-подбором:
он сравнивает с запросом все направления сразу (нечёткая оценка с весами), объясняет расчёт, считает
сумму поездки в $ и ₸ и понимает уточнения обычным текстом. Подбор работает без интернета. В отдельном
меню есть ИИ-консультант - чат о путешествиях на внешней языковой модели (через API). К результату подтягивается фотография направления
(Wikipedia), а для явно невозможных сочетаний (например, пляжный отдых в Антарктиде) система
честно объясняет, почему так, и предлагает реальную альтернативу.

## Открыть в браузере (в т.ч. с телефона)

**https://slavik2360.github.io/travel_destinations/**

Полный аналог десктопного приложения (`docs/`) - тот же мастер вопросов, оба режима подбора,
ИИ-консультант, абсурдный юмор, фото с Wikipedia, история и редактируемая база знаний. Своего
сервера нет (кроме необязательного прокси для ИИ): история и добавленные направления хранятся локально на устройстве
(localStorage), поэтому не синхронизируются между разными телефонами/компьютерами.

## Скачать и запустить (без установки Python)

Готовые сборки для Windows и macOS собираются автоматически в
[GitHub Actions](../../actions/workflows/build.yml) при выходе новой версии (тег `vX.Y.Z`) и
прикрепляются к разделу [Releases](../../releases). Скачайте архив под свою систему,
распакуйте и запустите - никаких дополнительных установок не требуется.

Если готовой сборки под свою систему нет - запустите workflow вручную (вкладка **Actions**
→ **Build standalone app** → **Run workflow**) и заберите файлы из артефактов запуска.

## Запуск из исходного кода

```bash
python3 -m venv env
source env/bin/activate   # Windows: env\Scripts\activate
pip install -r requirements.txt
python MyProgram/main.py
```

## Сборка приложения самостоятельно

```bash
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name TravelExpert MyProgram/main.py
```

Готовый файл появится в папке `dist/` (`TravelExpert.exe` на Windows, `TravelExpert.app` на
macOS).

## Подключение ИИ-консультанта

Нужно только для чата; подбор направлений работает без него.

Ключ API в код и репозиторий не записывается. Ключ подключается одним из двух способов:

- **Для себя:** меню ИИ → шестерёнка в углу → «Дополнительно» → режим и «Ключ доступа» (на десктопе
  можно через переменные окружения `OPENAI_API_KEY` / `GEMINI_API_KEY` / `GROQ_API_KEY`). Ключ хранится только на этом
  устройстве, у каждого режима свой.
- Режимы: `1` - OpenAI, `2` - Google Gemini, `3` - Groq. Режим по умолчанию - `DEFAULT_PROVIDER` в
  `MyProgram/ai_service.py` и `docs/ai.js`.
- **Для всех пользователей:** развернуть прокси из папки [proxy/](proxy/README.md). Ключ лежит на
  сервере, пользователям он не нужен и не виден.

Суммы поездок - оценка, а не реальные цены. Курс тенге:
[Rates By Exchange Rate API](https://www.exchangerate-api.com).

## Структура

- `MyProgram/main.py` - база знаний, логика подбора, основной интерфейс на PyQt5.
- `MyProgram/smart_engine.py` - собственный ИИ подбора: оценка, стоимость, разбор уточнений.
- `MyProgram/ai_service.py` - ИИ-консультант: настройки, сетевой клиент, промпт; курс тенге.
- `MyProgram/ai_windows.py` - окна ИИ: меню, консультант, настройки, карточка стоимости.
- `MyProgram/shema.html` - схема логики мастера вопросов и механизма вывода (открыть в браузере).
- `MyProgram/db-schema.html` - ER-схема базы данных: таблицы, ключи и связи между ними
  (открыть в браузере).
- `docs/` - веб-версия приложения (HTML/CSS/JS, без сборки), раздаётся через GitHub Pages.
- `proxy/` - необязательный прокси для консультанта (Cloudflare Workers), хранит ключ на сервере.
