# Прокси для ИИ-консультанта

Хранит ключ API на сервере, чтобы приложением могли пользоваться все, а ключ не видел никто.

## Развёртывание (Cloudflare Workers)

Нужны Node.js и бесплатный аккаунт Cloudflare.

```bash
cd proxy
npx wrangler login
npx wrangler secret put AI_API_KEY_2   # ключ режима 2 (для режима 1 - AI_API_KEY_1, для 3 - AI_API_KEY_3)
npx wrangler deploy                  # в ответ придёт адрес вида https://travel-ai.<имя>.workers.dev
```

Какой режим ИИ используется, задаёт `PROVIDER` в `wrangler.toml`: `1` (OpenAI) или `2` (Google Gemini).

Затем впишите адрес с `/v1` на конце в `PROXY_URL` в двух файлах:

- `MyProgram/ai_service.py`
- `docs/ai.js`

После этого ключ в приложении не нужен.

## Бесплатный ключ Gemini - только для тестов

Условия Google: 18+, нельзя отправлять личные данные, запросы могут использоваться для улучшения
продуктов Google, а приложение для пользователей из ЕЭЗ, Швейцарии и Великобритании требует платного
тарифа. Перед раздачей приложения людям перечитайте условия: https://ai.google.dev/gemini-api/terms

## Защита от лишних трат

Адрес прокси узнать можно, поэтому задайте месячный лимит расходов в кабинете провайдера API.
В самом прокси: одна модель, до 64 КБ на запрос, предел длины ответа и 10 запросов в минуту с
одного IP (`wrangler.toml`).

Ключ не записывайте ни в код, ни в `wrangler.toml`: только через `wrangler secret put`.
